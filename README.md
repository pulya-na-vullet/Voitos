# Voitos — персональный AI-помощник в MAX (MVP v0.1)

Персональный помощник для одного пользователя: память, задачи, напоминания, голос → текст, YandexGPT.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
python app.py
```

Откройте панель: [http://127.0.0.1:18765/panel/](http://127.0.0.1:18765/panel/)

Логин по умолчанию: `admin` / `admin` (меняется в `.env`).

В разделе **Настройки ИИ / MAX** укажите:

1. токен бота MAX;
2. Yandex API Key и Folder ID;
3. модель (по умолчанию `yandexgpt-lite`).

После сохранения напишите боту в MAX. Первый пользователь автоматически становится единственным разрешённым.

## Что делает `python app.py`

При каждом запуске:

- ставит зависимости при необходимости;
- выполняет миграции SQLite;
- создаёт админа и сиды настроек;
- снимает дамп БД;
- поднимает веб-панель (Waitress);
- запускает long-poll воркер MAX;
- запускает планировщик напоминаний;
- каждый день пишет дамп в `data/dumps/`;
- **перезапускает** упавшие фоновые процессы.

Сервер слушает `0.0.0.0:18765` — клиент может подключаться к панели по IP вашего компьютера (откройте порт в файрволе при необходимости). Порт задаётся в `.env` (`PORT=`).

## Возможности бота

| Действие | Пример |
|---|---|
| Память | «Купила холодильник Bosch.» → «Запомнил.» |
| Явно запомнить | «Запомни это.» |
| Не запоминать | «Не запоминай.» |
| Поиск | «Что ты помнишь про холодильник?» |
| Задача | «Нужно купить подарок маме.» |
| Список задач | «Что мне нужно сделать?» |
| Выполнено | «Выполнил подарок.» |
| Напоминание | «Напомни 20 числа оплатить коммуналку.» |
| Голос | голосовое → SpeechKit → тот же пайплайн |

Категории памяти: Покупки, Дом, Автомобиль, Финансы, Здоровье, Предпочтения, Люди, Идеи, Прочее.

## Админ-панель

- все сообщения клиента;
- память / задачи / напоминания с удалением;
- лог работы;
- диаграмма активности за 14 дней;
- настройка Yandex AI и токена MAX;
- ручной дамп БД.

## Структура

```
app.py              # точка входа + супервизор процессов
config/             # Django settings / urls
database/           # модели SQLite + дампы
bot/                # MAX API, доступ, пайплайн сообщений
ai/                 # абстракция LLM/STT + YandexGPT + SpeechKit + intent
memory/ tasks/ reminders/ logs/ panel/
data/voitos.sqlite3
data/dumps/
logs/voitos.log
```

Архитектура LLM сменна: новый провайдер = класс на базе `ai.base.LLMProvider` + правка `ai.factory`.

## База данных

SQLite (`data/voitos.sqlite3`). Ежедневные копии: `data/dumps/voitos_YYYYMMDD_HHMMSS.sqlite3`.

## Подписка и несколько пользователей

- Бот доступен **нескольким** пользователям MAX.
- Админка: список пользователей → карточка (обзор / сообщения / память / задачи / напоминания / лог / чеки).
- Оплата: перевод на номер из настроек (по умолчанию `89625507832`, получатель Григорьев Дмитрий Вячеславович), **100 ₽ / мес**.
- Пользователь присылает **фото чека** → OCR (Yandex Vision) + разбор ИИ → чек в админке.
- Админ **Принимает** / **Отклоняет** — пользователю уходит сообщение в MAX.
- Сумма 250 ₽ → 2 месяца и т.д. (`сумма // 100`).
- После истечения — 2 дня льготного периода, затем функции закрываются до оплаты.

## Важно

- Бот только для одного `user_id` MAX.
- Фото/PDF/календарь/семейные аккаунты — вне MVP, но модули готовы к расширению.
- Для production за файрволом смените `SECRET_KEY` и пароль админа.
- Модель в настройках — только YandexGPT (`yandexgpt-lite` / `yandexgpt`), не DeepSeek.
- Если бот молчит: нажмите **Проверить MAX** на обзоре, убедитесь что статус `polling`, затем напишите боту снова. При старте webhook-подписки снимаются автоматически (иначе long polling не получает сообщения).
- Ошибка `CERTIFICATE_VERIFY_FAILED` к `platform-api2.max.ru` — нужен сертификат Минцифры. Он уже лежит в `certs/`. Обновите проект и перезапустите. В крайнем случае в `.env`: `MAX_SSL_VERIFY=false`.
